# Prashant LMC Thapa | Portfolio Website

A professional personal portfolio website built for Prashant LMC Thapa, designed to showcase his academic background, work experience, project learning, blog content, and technical growth as a future Data Analyst.

## Project Overview

This portfolio was developed as a static, responsive personal website using HTML, CSS, and JavaScript. The goal was to present a polished and professional online identity that can be deployed easily on a static hosting platform.

The site includes:
- a personal landing page
- about section with academic background
- journey timeline
- skills section
- projects showcase
- experience section
- blog section with article pages
- contact form
- downloadable CV PDF
- dark/light theme support
